# Data provenance

The original archive was downloaded on 30 October 2026 from the public Kaggle endpoint for [blastchar/telco-customer-churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn).

- Original file: `raw/WA_Fn-UseC_-Telco-Customer-Churn.csv`
- SHA-256: `88be4b93fbe0cc83421af1c503794c97c342eca914c1576db7c276e61d61358a`
- Records: 7,043 fictional customers; 21 columns; 19 predictors.
- Target: Churn (Yes/No), with 1,869 Yes and 5,174 No labels.
- Missingness: eleven whitespace-only TotalCharges fields; all have zero tenure.
- Duplicates: no duplicate records or customer IDs in the inspected original.

The source CSV is kept unchanged. Processed data is generated by deterministic trimming, schema validation and numeric parsing. Missing TotalCharges remains missing in the processed CSV; the model's fitted training-only pipeline handles imputation. No customer records are deleted or synthetically substituted. All reported numerical findings are calculated from this file.

This is a fictional cross-sectional IBM sample. Dates, sampling weights, a prospective outcome window and intervention outcomes are absent. Do not claim real production validation, forecast validity or causal retention effects.

The project's MIT license applies to its original code and documentation, not to the source data. On 31 October 2026 the Kaggle data card displayed “Data files © Original Authors”. Raw and processed customer CSVs are therefore excluded from the public repository; users acquire the original directly from Kaggle using scripts/acquire_data.py, which verifies its checksum. Local acquisition and analysis succeeded without Kaggle credentials. If future download access changes, manually download the original file into raw/ and run scripts/acquire_data.py to verify it. The delivered local project still contains the inspected data.
